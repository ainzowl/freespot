Setup

Nothing to configure

Search, browsing and playback work out of the box — no account, no API key, no server. The only optional key is for saving tracks offline.

Playback and search

Ready — no key needed

Songs stream through YouTube's own player. Search, artists, playlists and trending come from public Piped instances. Neither asks you for a token.

Download provider key

Using the built-in key · optional

From video-download-api.com. A built-in key ships with the app, so downloads work with nothing to configure. It is only a fallback — free public mirrors are tried first, so most tracks cost nothing.

A key you add stays in this browser. The built-in key is part of the public app, so treat it as shared and replace it if you need your own quota.

How it works

  1. Playing a song uses a hidden YouTube player — free, no key, no download.
  2. If an owner disabled embedding, the same audio plays through a public mirror instead.
  3. Downloading saves the song inside the app so it plays with no signal.
  4. Downloads try free public mirrors first; the key above is only a fallback.
  5. Downloaded tracks play from the app's own storage instead of YouTube, even offline.
